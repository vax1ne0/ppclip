# Task chat

Run scoping, follow-up run dividers, Worked rows under replies, and matching agents by ID in task chat.

**Settings → ppclip switch:** Task chat → Clearer run activity

Files here sit at the same paths they get inside Paperclip (`ui/src/ppclip/task-chat-`). Edits to official files that wire this module in live in `hooks/<version>/hooks.patch`, marked `// ppclip:`.
